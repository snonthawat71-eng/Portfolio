# เว็บ Portfolio งานกราฟิกดีไซน์

เว็บไซต์หน้าเดียวสำหรับโชว์ผลงานเพื่อใช้สมัครงาน รองรับ 2 ภาษา (อังกฤษ/ไทย)
สร้างด้วยเว็บแบบพื้นฐาน (HTML/CSS/JavaScript) จึงเปิดดูได้เลยและฝากออนไลน์ฟรีได้

> **ตอนนี้รูปทั้งหมดเป็นรูปตัวอย่าง (placeholder)** ไว้ให้เห็นหน้าตาก่อน
> ค่อยเอารูปงานจริงไปแทนทีหลังตามวิธีด้านล่าง

---

## วิธีเปิดดูเว็บในเครื่อง
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย)

---

## ไฟล์ไหนทำหน้าที่อะไร (อ่านเผื่อรู้ ไม่ต้องจำ)
| ไฟล์ | หน้าที่ |
|------|--------|
| `index.html` | หน้าเว็บหลัก (Hero, ผลงาน, About, Contact) |
| `work.html` | หน้ารายละเอียดผลงานแต่ละชิ้น |
| `data/works.js` | **รายการผลงาน** ← มาแก้ที่นี่เวลาเพิ่มงาน/เปลี่ยนรูป |
| `scripts/i18n.js` | ข้อความสองภาษา (เมนู หัวข้อ) |
| `styles/main.css` | หน้าตา/สี/ฟอนต์ |
| `assets/works/` | รูปผลงาน |
| `assets/resume.pdf` | ไฟล์เรซูเม่ |

---

## 🖼️ เปลี่ยนรูปตัวอย่างเป็นรูปงานจริง
1. เอารูปงานของคุณ (ไฟล์ `.jpg` หรือ `.png`) ไปวางในโฟลเดอร์ `assets/works/`
2. เปิดไฟล์ `data/works.js`
3. แก้บรรทัด `cover` และ `images` ให้ชี้ไปที่รูปของคุณ เช่น
   ```
   cover: "assets/works/รูปของฉัน.jpg",
   images: ["assets/works/รูปของฉัน.jpg", "assets/works/รูปที่สอง.jpg"],
   ```

## ➕ เพิ่มผลงานใหม่ 1 ชิ้น
ในไฟล์ `data/works.js` ก๊อปบล็อก `{ ... }` หนึ่งก้อน วางต่อท้าย แล้วแก้ค่าข้างใน
(`id` ห้ามซ้ำกับชิ้นอื่น และอย่าลืมมีเครื่องหมาย `,` คั่นแต่ละก้อน)

## ✍️ แก้ชื่อ / อีเมล / ข้อความ
- **ชื่อและคำโปรย** หน้าแรก: แก้ที่ `scripts/i18n.js` (คีย์ `hero.title`, `hero.tagline`)
- **อีเมล**: แก้ใน `index.html` ตรงคำว่า `s.nonthawat71@gmail.com` (มี 2 จุด)
- **ลิงก์โซเชียล**: แก้ใน `index.html` ส่วน `<ul class="socials">`

## 📄 เปลี่ยนไฟล์เรซูเม่
เอาไฟล์ CV จริง (PDF) มาตั้งชื่อว่า `resume.pdf` แล้ววางทับไฟล์เดิมในโฟลเดอร์ `assets/`

## 🌐 เอาเว็บขึ้นออนไลน์ฟรี (GitHub Pages)
1. เข้าไปที่หน้า repo บน GitHub → กดแท็บ **Settings**
2. เมนูซ้าย เลือก **Pages**
3. หัวข้อ **Branch** เลือกสาขาที่ใช้ แล้วกด **Save**
4. รอสักครู่ GitHub จะให้ลิงก์เว็บมา เอาลิงก์นั้นไปใส่ในใบสมัครงานได้เลย
